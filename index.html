🛠 처음 한 번 준비하기 (약 20분, 무료·터미널 없음)

A. Firebase (휴대폰 → 전시 화면 중계)

  1. console.firebase.google.com에 교회 구글 계정으로 들어가 프로젝트 추가를 누릅니다. 이름은 예를 들어 xmas-gallery로 정하고, 애널리틱스는 꺼도 됩니다.
  2. 왼쪽 메뉴 빌드 → Firestore Database → 데이터베이스 만들기를 누릅니다. 버전을 물으면 Standard, 위치는 asia-northeast3 (서울), 프로덕션 모드를 고릅니다.
  3. Firestore의 규칙 탭에서 내용을 모두 지우고, 아래 규칙을 붙여 넣은 뒤 게시를 누릅니다.
  4. 왼쪽 위 톱니바퀴 프로젝트 설정 → 내 앱 → 웹(</>)에서 앱 이름을 넣고 등록합니다. 화면에 나오는 firebaseConfig 부분을 통째로 복사해 위 ‘Firebase 설정’ 칸에 붙여 넣습니다.
복사한 규칙을 Firestore ‘규칙’ 탭에 붙여 넣으세요.

B. 이 파일을 인터넷 주소로 올리기 (GitHub Pages)

  1. github.com에 로그인한 뒤 New repository를 누르고, 이름(예: xmas-gallery)을 넣고 Public으로 만듭니다.
  2. uploading an existing file을 누르고 이 파일을 올립니다. 올리기 전에 파일 이름을 index.html로 바꿔 주세요. Commit changes를 누릅니다.
  3. Settings → Pages에서 Branch를 main으로 고르고 Save를 누릅니다. 1~2분 뒤 https://아이디.github.io/xmas-gallery/ 주소가 생깁니다.
  4. 노트북에서는 그 주소로 접속해 이 화면을 쓰세요. 주소는 위 칸에 자동으로 채워집니다.

휴대폰이 보낸 사진은 전시 화면이 받는 즉시 Firebase에서 지워지고, 이 노트북에만 저장됩니다. 행사가 끝나면 ‘새 QR’을 눌러 이전 QR을 막아 두세요.

1 휴대폰 사진 자동 가져오기 — 폴더 방식 (인터넷 주소 없이 쓸 때)

연결된 폴더가 없습니다. 휴대폰 사진이 모이는 폴더를 연결하면, 새 사진이 들어올 때마다 자동으로 전시 화면에 나타납니다.
📱 휴대폰 사진을 노트북 폴더로 보내는 방법

방법 A. 구글 드라이브 (교사 여러 명이 찍을 때 추천)

  1. 노트북에 Google Drive 데스크톱 앱을 설치하고 교회 구글 계정으로 로그인합니다. 파일 탐색기에 ‘Google Drive’가 생깁니다.
  2. 구글 드라이브에 성탄전시사진 폴더를 만들고, 사진 담당 교사들에게 ‘편집자’로 공유합니다.
  3. 이 화면에서 사진 폴더 연결을 누르고 Google Drive → 내 드라이브 → 성탄전시사진을 고른 뒤 ‘보기’를 허용합니다.
  4. 교사는 휴대폰으로 그림을 찍고 구글 드라이브 앱 → 성탄전시사진 폴더 → ＋ → 업로드로 올립니다. 보통 몇 초에서 수십 초 뒤 화면에 등장합니다.

방법 B. 휴대폰 한 대로 바로 보내기

  • 갤럭시 + 윈도우 노트북: 퀵 셰어(Quick Share)로 보내면 노트북의 ‘다운로드’ 폴더(또는 그 안의 Quick Share 폴더)에 저장됩니다. 그 폴더를 연결하세요.
  • 아이폰 + 맥북: 에어드롭으로 보내면 ‘다운로드’ 폴더에 저장됩니다.

사진 찍는 요령

  • 종이를 어두운 천, 검은 색지, 진한 책상 위에 놓고 바로 위에서 찍습니다. 바닥과 종이 색이 다를수록 모양을 정확히 오려 냅니다.
  • 종이 전체가 화면 안에 들어오게, 그림자가 지지 않게 찍어 주세요.
  • 아이폰은 설정 → 카메라 → 포맷 → 높은 호환성으로 바꿔 주세요. 기본 형식(HEIC)은 열리지 않습니다.

📋 예배 당일 진행 순서
  1. 노트북을 프로젝터와 HDMI로 연결하고, 윈도우는 Win+P → 확장을 고릅니다.
  2. 이 파일을 크롬으로 열고 사진 폴더 연결을 합니다. 실물화상기가 있으면 카메라를 써도 됩니다.
  3. 전시 화면 새 창 열기 → 새 창을 프로젝터 화면으로 끌어다 놓고 더블클릭하면 전체화면이 됩니다.
  4. 아이들이 그리면 교사가 찍어 올립니다. 그림이 가운데에 크게 나타났다가 모양에 맞는 자리로 날아갑니다.
  5. 마지막 순서에서 구유로 모이기(G)를 누르면 별은 큰 별 곁으로, 하트·등불·그림은 구유 앞으로 모이고, 말씀이 떠오릅니다.
  6. 행사가 끝나면 백업 내보내기로 그림을 꼭 저장해 두세요.
Esc 나가기 · Space 촬영 · G 구유로 모이기
